# todoCLI
Simple CLI todo list tracker, stores tasks in json file

## command list
```
create <task name>
```
creates a new task and adds it to the list
```
delete <task id>
```
deletes a task based of its numerical id, found in the task list
```
list
```
displays list of stored tasks with their corresponding IDs
```
reset
```
reset todo.json, use to empty task list or if json file is invalid
